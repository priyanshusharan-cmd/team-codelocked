## Flagship Project — BitByBit

TeamCodeLocked's competitive-coding platform for BMSCE students: *"Master algorithmic problem-solving."*

**Platform features**
- Curated DSA problem set, filterable by difficulty and tag
- Daily Code Sprint and a daily community question/poll
- Live, proctored Contest Arena with a real-time leaderboard
- AI Code Coach (Gemini): progressive hints, approach reviews, test-case breakdowns
- Clans, Duels & Ghosts (live and async), mentor solution sharing
- Points, global rank, streaks, and verified downloadable certificates

### BitByBit 2.0 (June–July 2026)
- Weekly coding contests started **8 June 2026**
- Teacher-curated DSA challenges
- Certificates and Activity Points; prize pool ₹500+; entry fee ₹15
- **Premium (₹39/month):** 3 AI hints, 3 weekly coding problems, submission analysis (time complexity and efficiency), discussion forum
- **Exclusive contest:** open to the first 70 subscribers. 1st place ₹500 cash; 2nd and 3rd get a certificate and Activity Points.
- **Free for everyone:** daily coding problems and an admin hint
- **Query contacts:** Omkrrish Dubey, Dhruv G Nayak
