# Inspiration: The Case File

Each site below teaches one **quality** to borrow. Copy no layout, art, code or signature effect from any of them. All were checked live on 2026-11-28.

| Reference | Quality to borrow for The Case File |
|-----------|-------------------------------------|
| [MIT Mystery Hunt / Puzzle Club](https://puzzles.mit.edu) | Real puzzle culture, played straight. It commits to its world with no irony, and the rituals (a countdown, the hunt itself) are content. |
| [Hack the North](https://hackthenorth.com) | A handmade physical world as the first screen. The objects are crafted and specific, so the event feels like a place, not a template. |
| [Hack Club](https://hackclub.com) | A student community that sounds human: specific copy, real members, credible while playful. |
| [The Recurse Center](https://www.recurse.com) | Restraint in the words: one confident sentence, then real photos. |
| [Emil Kowalski](https://emilkowal.ski) · [animations.dev](https://animations.dev) | The motion bar: ease-out entrances, interruptible transitions, nothing that makes you wait. |
| [Rauno Freiberg](https://rauno.me) | Craft in the small things: focus rings, selection colour, hover details nobody asked for. |
| [Teenage Engineering](https://teenage.engineering) | Labels as design: typed, precise, functional labelling, which is exactly how case labels and exhibit tags should feel. |
| [Supabase Launch Week](https://supabase.com/launch-week) | A series of events presented as one season, which fits the Utsav cases as a set. |

## The club's own material (stronger than any of the above)

- **The Last Block poster:** red, ransom-note letters, "Every move reveals the truth." The club already uses mystery language.
- **Mind Snap poster:** orange-red grain, heavy navy type, cut-out camera, eye and stopwatch. "See it. Snap it. Recall it before it's gone."
- **The Challenge Room poster:** black with neon magenta and cyan, a brain and puzzle pieces. "Think fast. Adapt faster."
- **The group photo** in a PJ Block classroom, with the Mind Snap slide on the screen behind the group: Exhibit A.
